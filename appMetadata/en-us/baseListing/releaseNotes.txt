44.0.0
* Updated to Fedora 44.
* GNOME desktop support is back! Run a full GNOME Wayland desktop on WSL2 and connect using Windows App or Remote Desktop Connection.
* Automated desktop setup: run install-desktop.sh and choose your hostname, RDP port, username, and password.
* Improved desktop reliability with fixes for GTK rendering, Xwayland startup, and display and audio settings.
* Upgraded the x64 graphics stack to WSL-specific Mesa 26.2.4.
* Improved systemd integration and installation of required desktop components.
* Extended WSL1 compatibility fixes to Fedora 44, including gdk-pixbuf/glycin update protection.
* Improved first-run user creation, graphics permissions, and cleanup after failed password setup.
* Preserved the Xorg desktop installer for Fedora 43 and earlier.

Note: Fedora 44 desktop setup requires WSL2 and currently offers GNOME only. Keep Fedora Remix running while using the desktop.

43.0.0
* Updated to Fedora 43.
* Improved WSL1 compatibility, graphics setup, welcome guidance, and Windows Terminal defaults.
* Added upstream Direct3D 12 acceleration on ARM64.

42.1.0
* Updated to Fedora 42 and Mesa 25.0.4.
* Enabled systemd by default.
* Improved WSLg, audio, X11 fallback, D-Bus sessions, and XDG directory setup.
