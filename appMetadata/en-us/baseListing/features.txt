Built on Fedora 44, bringing a modern Linux environment to Windows.
Designed for Windows Subsystem for Linux, with support for WSL1 and WSL2.
Available for x64 and ARM64 Windows devices.
Access thousands of development tools, command-line utilities, and applications through Fedora repositories.
Install, update, and remove software using the DNF package manager.
Keep packages and Fedora Remix customizations current with the included update.sh and upgrade.sh commands.
Run many Linux graphical applications through WSLg without manually configuring a display server.
Install a full GNOME Wayland desktop on WSL2 with the guided install-desktop.sh script.
Connect to your GNOME desktop using Windows App or Remote Desktop Connection.
Automated desktop setup handles installation, services, certificates, and your chosen RDP connection settings.
Built-in systemd support on WSL2 for managing Linux services and user sessions.
Manage supported services on WSL1 using the included wslsystemctl command.
WSL-optimized Mesa graphics packages on x64 provide Direct3D 12 acceleration and video acceleration support.
Direct3D 12 graphics acceleration on ARM64 through Fedora’s graphics stack.
Includes wslu utilities for convenient integration between Linux and Windows.
Access Windows files and launch Windows programs from your Linux environment.
Integrated Windows Terminal profile for convenient command-line access.
WSL-aware shell configuration manages display, audio, runtime directories, and Windows interoperability.
Targeted compatibility fixes and package version management address WSL-specific issues.
Actively developed with improvements informed by community feedback.
